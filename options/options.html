Deep File Scanning

By default, a file VirusTotal hasn't seen before gets a neutral score — it's only checked against a hash cache, not actually scanned. Turning this on sends the file's actual content (not just its hash) to VirusTotal when it's unrecognized and under 32MB. This is a real privacy tradeoff — off by default. Local static analysis (file-signature, entropy, macro, and script checks) always runs regardless of this setting and never leaves your device.

On-Device AI Explanations

Uses Chrome's built-in on-device model (Gemini Nano / Prompt API) to turn a scan's numbers into a plain-English explanation. Nothing is sent anywhere — it runs fully on your device, no API key, no server. It only ever explains a verdict this extension already computed; it cannot change a trust score or risk level. The device may need to download the model (a few GB) the first time you use this. Requires a recent version of Chrome with the on-device model available — the popup will tell you if it isn't.

Email Security (Gmail — read-only)

Connects with the gmail.readonly scope only — never send, modify, or delete. This uses your own Google OAuth client, not a shared one, so SecureDownload AI itself never holds credentials to your account. Steps:

  1. In Google Cloud Console, create an OAuth 2.0 Client ID of type "Chrome Extension", using this extension's ID as the item ID.
  2. Enable the Gmail API for that project.
  3. Paste the Client ID below and click Connect.
